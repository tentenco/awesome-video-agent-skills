# Contributing to Awesome Video Agent Skills

Thank you for your interest in contributing to **Awesome Video Agent Skills**, curated by **Tenten AI**!

## Inclusion Criteria (收錄標準)

To maintain the highest quality and practical utility for video creators, agencies, and coding agents:

1. **GitHub Stars Threshold**:
   - **Main List**: Repositories must have **$\ge$ 300 stars** and have been pushed/updated within the last 6 months (or represent the canonical SOTA implementation).
   - **Watchlist (潛力觀察名單)**: High-potential, cutting-edge Agent Skills with `< 300 stars` that are actively used or tested in real-world pipelines.
2. **Agent-Native**:
   - The tool must be runnable or controllable by AI Coding Agents (via `SKILL.md`, MCP, CLI, SDK, or structured API). Pure mouse-only GUIs are not accepted.
3. **No Deprecated / Outdated Projects**:
   - We actively exclude abandoned projects (e.g., SadTalker, 2024 AnimateDiff, Coqui TTS).

## How to Submit a Pull Request

1. Fork this repository.
2. Add your project under the most suitable category.
3. Use the format:
   ```markdown
   | **[ProjectName](https://github.com/owner/repo)** <br>`owner/repo` | Interface / Stars | Features | 實戰點評 |
   ```
4. Include a clear explanation of *why* this tool is useful in a production video pipeline.
5. Submit the PR! We review and merge active submissions within 48 hours.
